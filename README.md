# Portfolio projects

В этом репозитории собраны краткие описания практических проектов, над которыми я работал. Часть коммерческого кода находится в приватных репозиториях, поэтому здесь приведены описания задач, технологий и моей роли без приватных данных, ключей и production-конфигураций.

## 1. Backend и автоматизация для VPN-сервиса

### Задача
Разработать backend-логику для сервиса с клиентскими приложениями, управлением пользователями, интеграциями и внутренними административными сценариями.

### Моя роль
Работал над backend-частью, API, базой данных, инфраструктурной логикой, внутренними метриками и вспомогательными скриптами.

### Что реализовывал
- REST API для клиентских приложений
- авторизацию и работу с пользователями
- структуру базы данных и миграции
- интеграции с внешними сервисами
- healthcheck-и и внутренние сервисные метрики
- вспомогательные shell/Python-скрипты для администрирования
- логику взаимодействия с VPN-серверами

### Технологии
Python, FastAPI, SQLAlchemy, Alembic, PostgreSQL/SQLite, Redis, REST API, JSON, shell scripts.
